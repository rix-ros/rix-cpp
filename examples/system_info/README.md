# System Info Example

This example demonstrates a node that provides system information using the rix-cpp framework. It shows how to gather and display system metrics or status.

## Files
- `main.cpp`: Entry point for the system info node.
- `CMakeLists.txt`: Build configuration for the example.

## Usage
1. Build the example:
   ```bash
   mkdir -p build && cd build
   cmake ..
   make
   ```
2. Run the system info node:
   ```bash
   ./system_info
   ```

## Features
- System metrics reporting
- Status display

## Requirements
- rix-cpp library
- C++17 or newer

See the main project README for setup instructions.
